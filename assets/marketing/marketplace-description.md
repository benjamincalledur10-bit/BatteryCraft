# BatteryCraft

**Save battery. Reduce heat. Keep playing.**

BatteryCraft automatically lowers Minecraft's power usage when your MacBook runs on battery. Connect your charger and it safely restores your original settings—no manual switching required.

## Automatic power profiles

BatteryCraft monitors the macOS battery state and selects the right profile:

- **Plugged In:** restores your original Minecraft settings.
- **Battery:** reduces unnecessary power usage while keeping gameplay smooth.
- **Low Battery:** applies stronger savings when power is running low.
- **Critical Battery:** prioritizes maximum battery life immediately.

Every profile is customizable. You control FPS, render distance, simulation distance, particles, clouds, entity shadows, biome blend and entity distance.

## Smart Recovery

Your original Minecraft settings are protected on disk while a power-saving profile is active. If the game crashes or closes unexpectedly, BatteryCraft can restore them the next time it starts.

## More features

- Visual configuration screen in English and Spanish
- Optional HUD with battery percentage, active profile and estimated time remaining
- Configurable notifications and profile-transition delay
- Native, rebindable Minecraft controls
- Sodium detection and optional entity-distance integration
- Experimental macOS thermal-warning mode
- Local session statistics and diagnostics
- Compatible with Fabric optimization modpacks

## Privacy

BatteryCraft runs entirely on your Mac. It requires no administrator privileges, telemetry or Internet connection.

## Requirements

- A MacBook running macOS
- Fabric Loader
- Fabric API
- Minecraft 1.21.x, 26.1.x or 26.2.x

BatteryCraft is client-side only and does not need to be installed on the server.

## Installation

1. Install Fabric Loader and Fabric API for your Minecraft version.
2. Download the BatteryCraft file matching your Minecraft version.
3. Move it into your Minecraft `mods` folder.
4. Press `O` to open the configuration screen or `B` to cycle modes.
